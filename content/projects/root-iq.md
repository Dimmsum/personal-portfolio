Root IQ is an agricultural management platform built at the Sagicor Innovation Lab, a partnership between Sagicor and the University of Technology, Jamaica. My work there is on the backend.

## What I did

- **API:** backend development on the Root IQ .NET API.
- **CI/CD:** set up GitHub Actions pipelines for three environments (dev, UAT and production), deploying Docker containers to AWS EC2.
- **Database docs:** documented 120+ stored procedures across 21 categories, in a format that's quick for developers and AI tools to search.
